关于我

白天写业务，晚上写 Bug；偶尔把 Bug 修成 Feature。 喜欢把复杂需求拆到产品经理开始反思人生，然后再把它们组装成更简单的方案。

我的拿手好戏是让页面从 会动 进化到 很快， 并努力让代码从 能跑 升级到 能看。 相信世界上没有解决不了的问题，只有不够幽默的提交说明。

dev-philosophy.js
// 极简开发理念 const devPhilosophy = { core: "性能与体验并存", principle: "极简、高效、可扩展", goal: "用代码创造价值", motto: "Less is more", vision: "让复杂的技术变得简单" };

不聊 KPI，只聊用户体验；不卷语法，只卷可读性。 写代码像讲段子：节奏要稳，梗要准，回车键敲下去要让人会心一笑。
